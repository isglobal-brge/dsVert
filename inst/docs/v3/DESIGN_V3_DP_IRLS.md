# dsVert v3: fixed-path DP Newton/IRLS implementation design

Phase A, 2026-10-15. **Design only; no implementation, benchmarks or tests run.**
Review status is recorded separately in `CONSENSUS_V3_DP_IRLS.md` against this document's SHA256. Consensus on issue #26 is not consensus on this implementation design. Phase B must wait for that explicit agreement; this Phase-A task does not start implementation.

## 1. Decision and scope

Use the **production cross-grid R/DSI lifecycle and durable stage executor**, with a new fused score/curvature program evaluated at one authenticated public coefficient vector. Borrow numeric components and protected validity handling from the formal route where applicable. Do not promote the formal optimizer lifecycle or build Newton out of serial R calls to scalar multiplication.

The deciding argument is lifecycle risk: both options need a new curvature producer and certificates, but cross-grid already reaches DataSHIELD. The new work is an iterative, signed sequence of DP vector releases; the existing executor alone does not implement that sequence. Keep its internal protected stages distinct from the externally released optimizer stages.

Tier 1 delivers binomial/logit and Poisson/log with signed offsets, coefficients, a qualified inference candidate, and explicit refusal. Tier 2 adds bounded person-additive equations. Tier 3 first considers independence GEE; random-intercept LMM is conditional. GLMM, MI, arbitrary-propensity IPW and LASSO inference remain research. This is an additional regime; existing grids and Synopsis artifacts retain their semantics.

## 3. Cost and schedule

There is **no measured v3 stage**. The estimates below are component extrapolations for planning, with named omissions. A DataSHIELD latency promise cannot be inferred from raw Go throughput.

The 1.4.2 K3 Cor smoke needed 17 serial 64-product exact-GC operations at about 2–3 minutes each: 34–51 minutes for those operations alone (maintainer observation, not a new measurement). Assembling a stage with that RPC pattern would be unacceptable. For a fresh weighted Gram and score use `q=p(p+1)/2+2p` secret products per row: q=12,25,75. Binomial weights can add another product per row; masks, clamps and truncation add work.

| 64 | 10 | 7.56 | 150–225 |

Scalar model: `0.094099*n*q + 0.03167*n` seconds, using `S:inst/primitive-v/costs_pod.json` mulq64 and the sigmoid component in `S:BENCH_GROUPED_CLAUSE5.md`. It includes repeated scalar setup and a binomial link proxy; it is neither a bound nor a measurement of the fused program. Poisson has the same product model but needs its own link/offset certificate and timing. Old-RPC model is `q*ceil(n/64)*(2–3)` minutes, assuming separate coordinate batches. These models exclude compiler, source materialization, noise, authentication and R/DSI delivery; they are not end-to-end forecasts.

`S:BENCH_V2.md` supplies the contrasting fused evidence:

- Certified 32-row × 8-candidate batches: 7.319 s binomial / 7.606 s Poisson on the pod, compilation excluded. A one-evaluation-per-row equivalent is about 1.8/1.9 s at n=64, 6.4/6.7 s at n=200, 29.3/30.4 s at n=1000, using full 32-row batches. This is only a loss/link throughput anchor: score/H work is absent, and dividing by eight assumes amortization that a one-point circuit must earn.
- Full n=10000, benchmark p=10, 50-candidate runs: binomial 2795.701 s / 86.52 GB; Poisson 2695.032 s / 106.76 GB. Includes compilation and joint noise; excludes authenticated R/DSI. Four peer pairs shared a 7.65-core quota. In that driver p counts predictors separately from the intercept, unlike this document.
- Exported `ds.vertGLM()` n=2000/p=6/grid=2 calls: binomial 2767–3216 s (46–54 min), Poisson 3196–3782 s (53–63 min), excluding prior PSI/signature setup. This is the strongest warning against claiming a seconds-long DataSHIELD stage from the fused table.

Use one fused protected program per row tile, reuse compiled public topology, batch authenticated frames, and keep public-beta products local on shares where the certified encoding permits it. Phase B must separately record compile, protected compute, materialization, noise and DSI transport. New v4 noise latency and d=65 costs are unmeasured. For T updates, sum their full/score-only costs and add one terminal audit if inference is requested; no inference work is hidden in the table.

**Schedule decision:** implement signed refresh masks. First bring up H at every stage because it exercises the full interface; qualify first+last refresh and chord as separate profiles. Do not declare a universal default. Claude's stress test shows first-only H gives 17.5% coverage at moderate effects even without floor/box flags; every-stage H can be unstable at smaller n. A predeclared effect/domain profile may choose a schedule before data access. No analyst tuning, exact-score stopping or private loss line search. Changing a schedule means a different signed release with composed privacy cost.

## 4. Path integrity and deterministic public arithmetic

The maintainer's two-authority successor proposal is sound **only if each authority recomputes the successor and signs the same canonical bytes**. A signature on analyst-supplied beta is insufficient.

Let optimizer releases be t=0,…,T−1, evaluated at beta_t; each produces beta_(t+1). If sampling inference is requested, a fixed terminal audit at t=T evaluates g/H at beta_T and makes no update. Its budget is explicit. This fixes the off-by-one problem in using H_(T−1) as information at beta_T. Estimate-only contracts may omit that audit. Start is signed zero or an explicitly identified, previously budgeted DP pilot; no user start value.

Use integer lattice outputs and **exact rational public arithmetic**. The authoritative server implementation is Go; the offline/client verifier is an independent bignum implementation (proposed R `gmp::bigq`), sharing specification and known-answer fixtures, not calling the same Go binary as its only check. Signed contract values are integer strings / reduced rational pairs; no JSON floating point, NaN, signed zero, locale or BLAS eigenvectors in the authoritative path.

1. Decode/subtract the signed-vector translation (§5); reconstruct symmetric H in signed upper-triangle order. Reused H is identified by its original release digest.
2. Choose the smallest nonnegative integer k such that `H + k*q_floor*I − floor*I` is PSD. Test exactly by rational LDL elimination in fixed coordinate order: negative pivot fails; zero pivot with nonzero residual row fails; a zero row is skipped. Exponential bracketing then integer bisection determines k. This is a **diagonal shift**, not the issue's spectral eigenvalue clipping; record it as a distinct update version.
3. Solve `(H+k*q_floor*I+lambda*I) v = g−lambda*beta` by rational elimination. The positive signed floor makes the solve unique. First replace v by a_t*v, with signed rational `0<a_t≤1`; then apply the L-infinity trust scale `min(1,r_t/||v||inf)`, `r_t≥0`. A zero vector has scale 1. This order is part of the update version.
4. Project componentwise onto the signed box and round once to the beta lattice, nearest with ties to even. Box endpoints lie on that lattice. Sign the result, shift, trust/projection flags, predecessor digest, stage ID and update-version digest. No floating-point recomputation can substitute for this value.

Public arbitrary-precision work uses only DP outputs. A signed resource ceiling may fail closed based on those outputs; it must not switch update algorithms. The exact PSD test, bounded precision of the input lattice, solve, rounding and canonical serialization get cross-platform known-answer fixtures in Phase B. Numerical display and experimental covariance may use floating point; all security decisions use the canonical values or signed deterministic interval bounds.

Specify fraction-free Bareiss elimination with fixed pivot order for the positive-definite solve, and the equivalent fraction-free PSD elimination with the zero-pivot rule above. Let R_H be the maximum public absolute row-sum bound on any decoded H (from its finalizer limits). Gershgorin gives the signed maximum shift `k_max=ceil((floor+R_H)/q_floor)`. Bracketing never exceeds it; failure there rejects the path, not the arithmetic rule. Clear denominators using a publicly bounded common denominator. If all augmented integer matrix entries have magnitude ≤2^w, every k-minor has magnitude ≤`k^(k/2)*2^(k*w)` by Hadamard. Set `L=p*w+ceil((p/2)*log2(p))+2`; Bareiss minors require at most L bits and multiplication-before-division at most 2L+2. The numeric certificate derives w from decoded-coordinate, k_max, ridge, beta and rational-constant widths, and bounds every subsequent damping/trust/addition operation. It must show the fixed signed temporary ceiling (a conservative proposed ceiling is `8L+16w+64` bits) covers that exact DAG. Round beta back to its fixed lattice every stage, so denominator growth does not accumulate across T. Contract admission rejects a profile without this bound; runtime never chooses a larger ceiling adaptively.

Every server verifies unanimous custodian contract signatures, full pinset/designated pair, frozen epoch vector, stage number, complete prior publication signatures, predecessor chain, exact beta recomputation and numeric profile before protected work. Source owners verify the same stage purpose before issuing ciphertexts. Each authority durably reserves one successor for `(root,t)` and rejects forks even if a request supplies another plausible predecessor. Client repeats these checks before starting/resuming and validates the complete returned chain. Relay transports authenticated purpose-bound frames; its checks are optional for confidentiality, and drop/reorder/replay/tamper cannot cause an alternative accepted point.

Persist stage DP payload and public certificate before acknowledgment; persist the matching successor before accepting the next stage. Retry after a partial publication returns the retained bytes/signatures. Internal protected attempts may have fresh masks after mutually acknowledged abort, as the existing executor allows; this never changes semantic noise identity. Once committed, lost/corrupt state is a hard failure, never a fresh noise draw. Timestamps, attempt IDs and transport receipts stay outside canonical release bytes and sticky keys. Crash after only one authority commits is recovered by matching durable PREPARE/COMMIT records, not by re-running with a new root.

## 5. Release identity, vector geometry and privacy accounting

Define root identity from canonical semantic contract (excluding display aliases), complete provenance epoch vector, signed source/schema/level/owner declarations, numeric/sampler/update versions and any pilot digest. Define

`K_t = H("dsvert-v3-irls-stage-v1", root, purpose_t, t, predecessor_public_payload_digest)`, with distinct signed purposes `optimizer` and `terminal-audit`.

At t=0 the predecessor is the root/start certificate. Hash the canonical **public DP payload**, not signature randomness, private input commitments, attempt receipts or data bytes. Per-authority noise PRFs also domain-separate role, block and coordinate. Alias analysis IDs resolve to the same root. The predecessor key is safe only with the single-successor rule above; it must not offer an analyst a fork namespace.

Choose **one dual-signed artifact per stage**, plus a final composite certificate listing their digests, budgets and endpoint. The composite is an index, not another draw. It includes partial-stage accounting if execution stops. Charges are per distinct logical release; retries do not create new releases or refunds. The contract reserves the entire path before stage 0; software enforces that finite path's allocations, not a global patient budget.

Reuse the current Synopsis execution/receipt/publication adapters (`S:R/dpSynopsis{Analysis,Execution,Lifecycle,Receipt,Artifact}DS.R`), with a new multi-stage semantic schema. Their existing single `final_noise` lane does not by itself express a schedule. Do not import the retained legacy `jointDPVectorReleaseLedger.R` lifetime quota into this route.

**Primary noise:** explicitly select `independent_full_global_draw_convolution_ring128_v4` for every dimension. `S:inst/dsvert-mpc/k2_joint_dp_exact_laplace.go` provides exact geometric-difference lattice Laplace; `k2_joint_dp_vector_convolution_v3.go` implements the vector-convolution/finalization architecture. Existing automatic cross-grid selection has a 51-coordinate policy, while d=65 needs an explicit v3 policy; v4's vector support is not itself a proof of this geometry.

For integer-valued scaled query `v=(g/s_g,vech(H)/s_H)/h`, certify its joint integer L1 sensitivity S1 including all rounding. Each authority independently samples **a full** coordinate Laplace vector at `alpha=epsilon_t/S1`. With `q=exp(-alpha)`, one geometric-difference coordinate has variance `2q/(1−q)^2`; two draws give `4q/(1−q)^2`, before decode/clamp. Multiply by `(h*s_j)^2` in physical units. The continuous `4b²` formula is only an approximation. Independent full draws protect the view conditional on either authority's own randomness; never halve the calibrated scale. Report epsilon_t once, not twice, for the resulting convolution under the stated non-collusion model.

Alternative supported geometry: give score and H separate signed budgets `epsilon_g,t + epsilon_H,t = epsilon_t`, use each block's full L1 sensitivity, concatenate both blocks into one stage publication. It is one artifact but two composed mechanisms. A zero H budget means reuse, not release without noise. Fix either scaled-joint or split-block geometry in the contract; do not mix their calibrations. Baseline implementation uses split blocks to reproduce the schedule experiment, with authenticated vector subcalls and atomic publication of both blocks.

The split-block adapter is new. Derive immutable child identities `(K_t,"g")` and `(K_t,"H")`, retain each noised block under its own fixed geometry, and place a durable parent barrier before public access. Children have no independently readable publication endpoint. Both authorities commit both required blocks before dual-signing the single parent stage root and successor. Crash recovery reuses retained children; no block may reroll because its sibling failed. Conservatively account for any block already observable to an authorized party after an abort. Even if a transport failure reveals a partial DP block, the reserved full-stage budget covers it and no successor is accepted until the parent completes.

Both lanes partition **one committed protected evaluation output**, including its validity/provenance binding; they are not two independent source evaluations. Stage COMMIT/publication requires both lanes' noised final shares durable at both authorities. A crash between lanes resumes only the missing lane under its fixed key. The next predecessor digest hashes the canonical concatenation of g and H lane payloads in signed order. A score-only stage instead hashes its g payload plus the signed reference to the prior H artifact: epsilon_H=0 is not an empty or unnoised lane. Terminal-audit purpose is bound in both parent and child identities.

**Signed statistics adapter is necessary.** Current vector lattice/finalizer accepts nonnegative coordinates and clamps decoded outputs to `[0,U]` (`S:R/jointDPVectorCapsuleDS.R`, `.dsvert_joint_dp_vector_lattice_vectors`; Go vector-convolution finalizer). Scores and off-diagonal H can be negative. In common integer lattice units certify each actual rounded person coordinate `|v_c,j|≤c_int,j`, including numerical envelopes and row caps. Choose integer `A_j≥C*c_int,j+margin_j`, add A_j exactly once to one designated aggregate share, release in `[0,2A_j]`, then subtract A_j publicly. A_j uses padded capacity C, never exact participating count. Translation does not change sensitivity. A new lattice adapter must validate these bounds independently of the old nonnegative-family schema. Sign margins, upper limits and coordinate widths. Replay includes modular decode and output clamp; an endpoint hit causes inference refusal. Do not merely feed signed integers into the old unsigned path.

v4 draws are unbounded and reduced modulo 2^128; deterministic no-wrap cannot be promised. Modular decoding/clamping is DP post-processing, so its wrap bound is a **utility/inference tail**, not privacy delta. Require deterministic headroom for protected source arithmetic and translated noiseless aggregates, plus a signed outward noise sum-wrap bound charged to the inferential error allowance. Never detect a large draw and resample. Finite older samplers retain their own distinct delta/headroom contracts (`S:inst/docs/joint_dp_exact_laplace_ideal_bits.md`).

One joint draw is not the initial choice. The retained finite one-draw exact-GC Laplace needs positive implementation delta and has restrictive scalar/grid geometry; it is not v4 ideal-bit pure DP. Joint Gaussian requires its own signed (epsilon,delta)/rho law and calibration, not L1 Laplace constants. If later selected, use the L2 bound in §7, explicitly account for finite-law delta, and requalify the numerical/inference/cost profile. No unannounced sampler substitution.

For pure ideal-law Laplace, `epsilon_path = epsilon_pilot + sum_t(epsilon_g,t+epsilon_H,t) + epsilon_terminal + epsilon_other`. Include all inference meat/derivatives and model selection when present. Sum implementation deltas for any finite validity/conversion/sampler protocols; do not label such a complete route pure DP just because v4's noise law is pure. Carry the existing ideal-bits/computational-PRF and physical timing/availability limitations unchanged. Statistical diagnostic tail probabilities are a separate quantity from DP delta.

**#25 interaction:** freeze the full dependency-closure epoch vector for the entire path, including sources that affect membership but contribute no model column. New authorization produces a new random epoch even for identical data; a new root starts at beta_0. Mid-path epoch changes cannot splice onto old stages. Source material comes from frozen publications and private admission seals; never publish content hashes or derive sticky seeds from them. Reusing a previously released DP pilot across roots carries its existing composition history. Authorization/epoch changes are not privacy refunds. This preserves the provenance design in [issue #25](https://github.com/isglobal-brge/dsVert/issues/25).

Concrete reuse: `S:R/dpProvenance.R::dsvertAuthorizeSource`, `dsvertReauthorizeSource` and `.dsvert_dp_provenance_private_pin`; `S:R/dpSynopsisProvenance.R::.dsvert_dp_synopsis_closure_v2`, `_closure_validate_v2`, `_effective_dependencies_v2`. These authorization operations remain custodian-only. Publication/replay uses `S:R/dpSynopsisLifecycleDS.R::.dsvert_dp_synopsis_publication_v1` / `_publication_replay_v1`; it must report no new source read, sampler invocation or finalization on replay.

Distinct contracts/epochs compose. Current catalog authorization is not a global budget ledger or a finite lifetime guarantee. No trusted analyst identity is introduced. Keep unanimous signatures, pinned roles, fail-closed admission and the semi-honest, non-colluding two-compute-peer model; KOS and transport signatures do not establish malicious-secure arithmetic.

## 7. Sensitivity of the actual protected functions

Let a=1 for add/remove-person with padded zero slots, a=2 for conservative replace-one; C is public capacity, p includes intercept. Let `|x_j|≤b_j`, `B1=sum b_j`, `B2²=sum b_j²`; define `V1=((sum b_j)^2+sum b_j²)/2`, `V2²=((sum b_j²)^2+sum b_j^4)/2`. These are exact maxima of `||vech(xx')||1` and squared L2 over the coordinate box (attained at all coordinate magnitudes b_j). Off-diagonals occur **once**, without sqrt(2) weighting.

For per-row `u=x*r`, `h=w*xx'`, `|r|≤R`, `0≤w≤W`, rigorous joint bounds are

`Delta1 ≤ a*(R*B1/s_g + W*V1/s_H)`;

`Delta2 ≤ a*sqrt(R²*B2²/s_g² + W²*V2²/s_H²)`.

These are exact norm-envelope formulas for this vector encoding; they need not be tight sensitivity suprema because r and w depend on the same eta/y. With only `||x||2≤B` and `||x||1≤B1`, use `V1≤(B1²+B²)/2`, `V2≤B²`. Do not calibrate coordinate Laplace with Delta2.

For split blocks rounded once per person, let q=p(p+1)/2 and m_rows be the signed row cap. The per-lane integer sensitivities are `S1_g=ceil(a*(m_rows*R*B1/(s_g*h_g)+p/2))` and `S1_H=ceil(a*(m_rows*W*V1/(s_H*h_H)+q/2))`, with certified additional arithmetic envelopes where needed. Each lane uses its own `alpha_lane=epsilon_lane/S1_lane`, translation and integer lattice. Tighter final-integer caps may replace these bounds with their proof. Never substitute the joint S1 or total epsilon_t into a split lane's declared law. These lane formulas and the joint-vector formulas describe different calibrations.

**Binomial, one Bernoulli row/person:** protected outcome mapping enforces `y∈{0,1}` under the signed binary/missingness rule; any admission validity stays protected. Fractional responses in [0,1] satisfy the sensitivity envelope but do not qualify as Bernoulli likelihood data. Use `mu=clip(sigmoid_approx(eta),0,1)`, `r=y−mu`, `w=clip(mu*(1−mu),0,1/4)`. Thus R=1, W=1/4, giving score L1/L2 bounds B1/B2 and curvature bounds V1/4,V2/4. Literal positive-trial binomial counts require a separately signed trials cap; they are not covered by the Bernoulli bound. Numeric approximation changes accuracy, not the enforced envelopes.

**Poisson:** protected `y=clip(y,0,Y)`, `offset∈[o_min,o_max]`, full `eta=x'beta+offset∈[L,A]`, `mu=clip(exp_approx(eta),m,M)`, `m=e^L`, `M=e^A` rounded outward, `r=y−mu`, `w=mu`. Use `R=max(M,|Y−m|)` (or conservative max(Y,M)), W=M. Substitute those values above for exact L1/L2 envelopes. Count saturation and floor-to-integer rules are signed. Offset bounds apply before the link; bounding x'beta alone is insufficient. A finite y cap makes this a bounded-count estimating equation; ordinary untruncated Poisson inference needs the additional qualification in §8.

All bounds/clamps and masks are enforced **inside MPC**, including handling malformed or out-of-domain input encodings by the signed rules. This does not upgrade the semi-honest threat model. Do not condition a public response on an exact clamp-hit count. For the canonical inference lane, public coefficient/X/offset domains must prove eta and residual/person clipping inactive for all admitted records, except the declared count top-coding with separately bounded model error. A clipped-score Hessian must be the derivative of that score or be labeled a preconditioner; it cannot be relabeled inferential bread.

With m_c≤m rows per person, sum within the private, signed person layout before final lattice rounding; multiply row bounds by m, or enforce tighter whole-person score/H norm caps. If L2 caps G,K are used, L1 calibration requires `sqrt(p)*G/s_g + sqrt(p(p+1)/2)*K/s_H`, not G+K. A private group-size/overflow bit cannot escape; cap/mask according to the signed rule or use an already privacy-accounted validity protocol.

Round each scaled person coordinate to lattice h nearest-even. If coordinate error is ≤h_j/2, add `a*sum_j h_j/2` to physical L1 sensitivity and `a*sqrt(sum_j h_j²)/2` to physical L2 via the triangle inequality, then convert outward to integer sampler units. Floor rounding needs h_j, not h_j/2. Absent slots remain exactly zero. If rounding occurs per row, charge m times the slack instead. Earlier arithmetic errors require explicit coordinate envelopes or final MPC clamps; output-rounding slack is not a substitute for a full integer-DAG range/error proof. Sum ranges scale by public C. Prove no wrap in protected deterministic source arithmetic; noisy v4 modular wrap is treated separately as the utility tail in §5.

## 8. Inference candidate and refusal

Implement the local-quadratic replay candidate from Claude's script, corrected to replay the **entire signed update**: start/pilot, refresh/reuse schedule, two full discrete noise draws, finalizer clamp/translation, rational update, trust/projection, ridge and rounding. Center the surrogate score at beta_T using terminal H. Hold the released local quadratic fixed, simulate the T updates using fresh public simulation randomness, and estimate endpoint covariance V_DP. Include pilot randomness if the signed pilot model is available; otherwise refuse pilot-based sampling inference. A public deterministic replay seed and replicate count make outputs reproducible and are never used as protected release seeds.

For byte-reproducibility, pin the public PRNG/exact sampler version, seed derivation and stream order `(replicate,stage,block,coordinate,authority)`. Calculate means/covariances exactly as rationals from lattice endpoints; use rational inverses and outward certified intervals for square roots, tail functions and threshold comparisons. Ambiguous threshold intervals refuse. Canonical inference records contain rational values/intervals and reason codes; decimal display may use floating point. A fixed seed alone would not make R/BLAS covariance or p-value output deterministic.

Take model sampling approximation `V_sampling=H_terminal^-1` only in a qualified, unpenalized canonical likelihood lane. Set `V_total≈V_sampling+V_DP`. This is **not** an exact independence decomposition: DP noise independent of data does not make nonlinear estimation errors independent. Replaying one quadratic omits nonlinear data-model variation and cannot itself prove bias negligible. A full-mechanism parametric bootstrap is a later alternative with its own assumptions, not a free private-X resampling procedure; [Ferrando–Wang–Sheldon](https://proceedings.mlr.press/v151/ferrando22a.html) motivates that alternative in qualified settings.

The terminal audit is an **extra budgeted release**, although replay itself costs zero additional privacy. It improves endpoint diagnostics and sampling curvature; it does not validate Wald coverage automatically. Default qualification state is candidate/unavailable until the mechanism-level inference gate passes.

Refuse inferential columns if any of the following holds, using public contract fields or DP outputs only:

- Chain, identity, calibration or numeric certificate failure: reject the artifact, not merely its SE.
- Any path floor shift, trust truncation, box projection, finalizer saturation, or failed domain/rounding margin. Ordinary Wald also refuses lambda>0 absent a separately approved bias correction.
- Terminal information has no positive lower confidence bound, is too ill-conditioned, or noise/approximation dominates its signed tolerance. Last-H reuse without terminal audit is estimate-only in v1.
- The model is outside the qualification profile, repeated rows lack the required variance model, or score clipping changes the derivative/target without an approved inference construction.
- Optimization/numeric/model bias cannot be bounded below the signed tolerance; replay instability/Monte Carlo precision or bias check fails. Do not equate a small last noisy step with convergence.

A concrete conservative diagnostic to qualify in Phase B: allocate statistical tail probability alpha_diag over the actual stage noise laws; bound `||Z_g||2≤q_g`, `||Z_H||op≤q_H` (Frobenius upper bound suffices). With certified numerical errors E_g,E_H, take `m_end=lambda_min(Htilde_terminal)−q_H−E_H` and `r=||gtilde_terminal||2+q_g+E_g`. Exact rational PSD/interval tests can certify a lower m_end without platform-dependent eigenvalue decisions. For canonical logit and log-Poisson with inactive derivative-altering clamps, `H(b) >= exp(-D_eta)*H(beta_T)` throughout the signed box, where D_eta bounds its predictor span. Thus `m_box=exp(-D_eta)*m_end` and radius `r/m_box` conservatively bound distance to the constrained optimum; require a ball of that radius inside the box to certify an interior root. Otherwise refuse. Bound approximation error in the same units. This can be very conservative at small n or wide boxes.

Provisional qualification thresholds to sign and test, not claims of validity: alpha_diag=0.01, curvature-error ratio `(q_H+E_H)/lambda_min(Htilde)≤0.1`, infinity-norm condition bound ≤1000, and combined optimization/approximation/model-bias radius ≤0.1 times the smallest sampling SD. Start with 2000 reproducible replay replicates and refuse if a prespecified split-replay covariance precision check exceeds 10%. Freeze final thresholds only after the mechanism-level study. Report unconditional coverage, refusal frequency and accepted-fit coverage; selection by diagnostics can affect the latter. A diagnostic tail bound is neither privacy delta nor a proof of 95% coverage.

Any future nominal 95% profile must allocate its total 0.05 error allowance across the approximation method and diagnostic/model/wrap/numeric/replay allowances, or justify them jointly; it cannot add 0.01 diagnostic failure invisibly to a 0.05 Wald tail. No numerical allocation alone proves that the local-quadratic approximation has the advertised coverage.

For Poisson, top-coded y is not exactly an ordinary Poisson sample. Either label inference unavailable for the bounded estimating-equation target, or qualify an ordinary-Poisson approximation using a signed uniform tail/bias bound over mu≤M (e.g. cohort coupling error ≤C*Pr{Pois(M)>Y}, plus a bounded score-bias contribution), included in the inference error budget. This lane needs a public numerical certificate, not an observed zero-clipping claim. A censored-count likelihood or corrected robust score would be a new function/derivative, not an automatic fix.
